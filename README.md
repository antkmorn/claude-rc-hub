# Claude RC Hub

Приложение для macOS, которое держит [Remote Control](https://code.claude.com/docs/en/remote-control) Claude Code включённым для твоих проектов. Мак стоит дома, а ты работаешь с проектами с телефона или через [claude.ai/code](https://claude.ai/code).

## Что умеет

- **Само стартует** при входе в систему и через ~20 секунд подключает 5 последних проектов (или те, что ты закрепил ⭐).
- **Только соединение:** чаты не создаются сами, ты заводишь их с телефона, когда нужно.
- **Окно со списком всех проектов:** включить или выключить Remote Control, посмотреть статус и активные чаты, открыть проект на claude.ai.
- **Значок ✳︎ в строке меню** с теми же функциями, всегда под рукой.
- **Перезапускает упавшие сессии** с растущей паузой: 10 с → 30 с → 1 мин → 2 мин → 5 мин.
- **Не даёт Маку засыпать**, пока он на зарядке (отключается в настройках).
- **Недоверенная папка:** если `claude` ещё не доверяет папке, приложение подскажет, как это исправить в один клик.

Статусы: 🟢 подключён · 🟡 подключается · 🔴 упал · ⚪️ выключен · ⭐ в автостарте.

## Установка

Нужны [Claude Code](https://code.claude.com) (команда `claude`, ты должен быть в нём залогинен) и [Homebrew](https://brew.sh).

```bash
git clone git@github.com:antkmorn/claude-rc-hub.git
cd claude-rc-hub
./install.sh
```

Скрипт сам поставит `tmux`, создаст приложение **Claude RC Hub** в «Программах» и включит автозапуск.

## Как пользоваться

- **Открыть окно:** `Cmd + Пробел` → «Claude RC Hub», или пункт «🪟 Открыть окно» в меню ✳︎.
- **Подключиться с телефона:** открой приложение Claude → Code; включённые проекты будут в списке. Можно и через меню «⋯» → «Показать терминал сессии»: нажми пробел, и появится QR-код.
- **Выбрать проекты для автостарта:** нажми ⭐ у нужных. Если ничего не закреплено, берутся 5 последних по дате изменений.
- **«Папка не доверена»:** «⋯» → «Доверить папку» откроет `claude` в этой папке. Ответь Yes и включи проект снова.

По умолчанию проекты берутся из `~/PycharmProjects`. Другую папку можно выбрать в настройках (⚙).

## Полезно знать

- **Закрытая крышка.** С закрытой крышкой Мак засыпает, если к нему не подключён внешний монитор: так устроена macOS. Чтобы работать с закрытой крышкой, подключи зарядку и монитор.
- **Если закрыть хаб,** сессии продолжат работать. Снова запустить его можно, открыв приложение.
- **Файлы:** настройки лежат в `~/.claude-rc-hub/config.json`, лог — в `~/.claude-rc-hub/hub.log`.

## Удаление

```bash
./uninstall.sh
```

Скрипт остановит все сессии, уберёт автозапуск, приложение и `~/.claude-rc-hub`.

## Как устроено

Каждый проект — это отдельный процесс `claude remote-control` внутри `tmux` (у хаба свой сервер `tmux -L claude-rc`, твой обычный tmux он не трогает). Фоновый хаб (`claude_rc_hub.py`, меню ✳︎) запускает launchd. Окно (`window.py` + `ui.html`) сделано на [pywebview](https://pywebview.flowrl.com). Общая логика лежит в `rc_core.py`.
